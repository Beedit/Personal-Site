Hi, this is my first post on my blog now!

And! I will be complaining about making the blog!!

I wanted a simple site that didn't need much - just some markdown files that I could use to generate a static site from. So, I looked for static site generators. I had heard good things about [Hugo](https://gohugo.io/), and decided to try it. What ended up happening was a maddening 2 days of my life trying to get it to work. It would compile, work on my machine and then push to GitHub and fail to build!

After a long couple hours of trying everything, I decided Hugo was not what I wanted to be using after all. I could not get it to work full stop.

So that left me back at square one. So, I thought about what I was actually good at, landed on TypeScipt and decided "sure, learning next is a good idea. what could go wrong".

Honestly, so far it has been a breeze. Sure, my blog isnt statically generated anymore but I can actually write a very simple react app now. It's much more fun than I thought it would be x3

I have been using [this template](https://vercel.com/templates/next.js/portfolio-starter-kit) however significantly modified.
